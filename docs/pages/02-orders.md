# 2. الكوموندات — Orders

- **الملف:** `frontend/src/pages/Orders.tsx`
- **الراوت:** `/orders`
- **الصلاحية:** `view_authorized_records`
- **API:** `GET /orders` بمعاملات `{page, page_size: 20, q?, status_filter?}`.
- **عنوان الصفحة:** `DarijaStock — الكوموندات`.

## المحتوى
قائمة الكوموندات (صف الطلب الرئيسي / workflow queue) — للمراجعة، الفلترة بالحالة، والدخول للتفاصيل قبل التسليم/الفوترة.

### أعمدة الجدول (`DataTable`)
| العمود | الحقل | الأولوية |
|--------|-------|---------|
| رقم | `order_number` (بتنسيق code) | primary (عنوان الكارط فالموبايل) |
| التاريخ | `created_at` (formatDate) | — |
| الزبون | `customer?.name` (مقصوص) | — |
| الحالة | `status` → `<StatusBadge>` | badge (فوق الكارط) |
| المجموع | `total` (formatMoney) | tabular |

> تحت `md` كل صف كيولي كارط؛ الرقم هو العنوان، الحالة فوق، وباقي الحقول + الأفعال تحت.

### الفلاتر / البحث / الترقيم
- Input بحث `«بحث: رقم / اسم الزبون / مرجع»` + زر «بحث» (يدوي، ماشي على كل ضغطة حرف؛ Enter كيفعل نفس الشي).
- Select الحالة: «كل الحالات» (فارغ) + **الحالات الحقيقية كاملة** من `ORDER_STATUS_FILTERS`: جديد · قيد المراجعة · مأكد · محجوز · قيد التحضير · مسلّم · ملغى.
- تغيير الفلتر كيرجّع `page` لـ 1. الحالة (page/q/filter) **كتّحفظ فالـ URL**.
- `Pagination` (page size 20).

### سلوك التصفية
- ملي تكون هناك تصفية/بحث نشط، كيبان شريط: «{total} نتيجة مطابقة للتصفية الحالية» + زر «مسح التصفية» (`clearFilters`).
- Empty state كيتبدّل: «ما كاينش نتائج مطابقة» + hint «بدّل البحث أو التصفية» ملي تكون هناك تصفية، وإلا «ما كاينش كوموندات» + hint «ابدأ باستيراد مسجات الواتساب».

### الأفعال
- «كوموند جديد» (Plus) — **معطّل (`disabled`)** مع chip «قريبا» + `title` «هاد الميزة غادي تتزاد فمرحلة قادمة» (placeholder، بلا handler).
- الضغط على أي صف، أو زر «تفاصيل» (FileText) → كيتنقّل لـ `/orders/{id}`.

## الديزاين
- Card وحيد، والـ CardHeader في نفس الوقت toolbar (عنوان + فلاتر، `flex-wrap`).
- خلية اسم الزبون مقصوصة (`max-w-[16rem] truncate`).
