# 4. استيراد المسجات — Import

- **الملف:** `frontend/src/pages/Import.tsx`
- **الراوت:** `/import`
- **الصلاحية:** `import_messages`
- **API:** `POST /import/messages` بجسم `{messages: [{raw_text}], label: "WA-{timestamp}"}`.

## المحتوى
ألصق مسجات طلب WhatsApp خام، تحليلها تلقائياً (Darija NLP) لكوموندات مسودة، ومراجعة نتيجة كل رسالة (تم/مكرر/خطأ).

- **يمين Card «لصق المسجات»** (MessagesSquare): `Textarea` وحدة (rows=14)، مثال:
  `سلام، 2 كرتونة كوكا لتر 1 / 5 كيلو سكر`.
  - تحتها عدّاد مباشر **«عدد الرسائل: N»** (`aria-live="polite"`) محسوب بـ `splitMessages(text)` (تقسيم على سطور فارغة).
- **يسار Card «نتيجة المعالجة»** — بعد النجاح:
  - شريط ملخص: `دفعة #{batch_id}` (navy Badge) · «الإجمالي» · «تم» · «كوموندات» (أخضر) · «مكررة» (كهرماني) · «أخطاء» (أحمر).
  - لائحة رسائل قابلة للتمرير (`max-h-[55vh]`): `رسالة #{i+1}`، اسم الزبون، أول عنصرين مقروءين (`product_text — qty unit` + `+N عناصر`)، Badges تحذير (كهرماني)، + Badges على اليمين: رقم الكوموند (أخضر) / «مكرر» / «خطأ».
- **Dialog لكل رسالة** (`MsgDialog`, lg): badge الخطأ؛ «الزبون» (الاسم/الهاتف)؛ جدول «العناصر» بأعمدة «النص الأصلي»/«منتج»/«الكمية»/«الوحدة»؛ «تنبيهات»؛ «أسطر غير مفهومة».

## الأفعال
- «معالجة وإنشاء كوموندات» (Send) → `POST /import/messages` (الـ client كيقسم النص على سطور فارغة لرسائل عبر `splitMessages`). الزر كيدوز على `useSubmitLock` (`loading={busy}`) ضد الإرسال المزدوج.
- «مسح» (outline) → كيمسح الـ textarea محلياً (معطّل إلا كان النص خاوي).
- «تفاصيل» لكل رسالة → كيحل Dialog محلي (بلا API).

## الديزاين
- تخطيط `xl:grid-cols-2` (بطاقتان)، فارغ: «مازال ماشي معالجة» / hint «ألصق المسجات واضغط معالجة».
- تحقق: toast «أدخل مسجات الواتساب على الأقل» · نجاح: «تم المعالجة: N كوموند / N مكرر».
